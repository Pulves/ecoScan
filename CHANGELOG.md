# Changelog

## 1.0.0 - Prototipo inicial do EcoScan

### Adicionado

- Tela de login com identidade visual do EcoScan.
- Tela de historico de plantas identificadas.
- Tela Minha Biblioteca com plantas adicionadas pelo usuario.
- Tela de captura com pre-visualizacao ilustrativa e botao de camera.
- Fluxo simulado de deteccao de planta.
- Navegacao inferior entre as telas principais.
- Permissao de camera no AndroidManifest.
- Teste de widget para validar a navegacao principal.

### Pendente

- Integracao com camera real do dispositivo.
- Modelo de deteccao de plantas.
- Persistencia de historico e biblioteca.
- Autenticacao real de usuario.
